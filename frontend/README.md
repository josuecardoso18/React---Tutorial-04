# DevFlix — React Tutorial 02

Projeto de catálogo de cursos de programação desenvolvido com React e Vite para a atividade do Senac RJ.

## Funcionalidades
- Menu com navegação Home, Frontend e Backend.
- Seções Frontend e Backend com três cards cada.
- Cards coloridos no estilo do exemplo da aula.
- Seleção de aula com `useState`.
- Player com `iframe` para os vídeos que têm `videoId`.
- Para os cards sem vídeo definido no material, o player oferece uma pesquisa no YouTube.

## Executar
```bash
npm install
npm run dev
```
Abra o endereço informado pelo Vite.
